# 徽派家私项目测试用例集

## 1. 使用说明

本用例集按当前项目模块拆分，适合作为：

- 手工提测清单
- 发布前回归最小集
- 缺陷修复后的针对性回归集

优先级说明：

- `P0`：阻塞上线
- `P1`：高频核心路径
- `P2`：增强和补充验证

## 2. 测试用例模板

| 字段 | 示例 |
| --- | --- |
| 用例编号 | `BUD-03` |
| 模块 | 项目预算管理 |
| 前置条件 | 已存在预算记录且包含成本中心和成本项 |
| 步骤 | 打开预算管理页面；选择项目；查看表格金额显示 |
| 预期结果 | 金额固定保留两位小数并使用正确千分位 |
| 优先级 | P0 |
| AI 辅助点 | 自动识别金额显示相关变更并加入回归清单 |
